NACHIYAR CHIT FUND – RIGHT-SIDE PAGE IMAGES
===========================================

HOW TO ADD THE IMAGES
1. Generate each image below in Gemini, ChatGPT, or any AI image tool.
2. Save it with the exact file name shown (.jpg, .png or .webp all work).
3. Put all files in this folder:  Nachiyar Website\assets\img\pages\
4. Refresh the website (Ctrl + F5). Each page shows its image automatically,
   inside the gold arch frame on the right side of the banner.
   Until an image is added, that page keeps its current gold animation.

SIZE FOR EVERY IMAGE: portrait, 4:5 ratio (for example 1200 x 1500 pixels).
Keep the main subject in the centre/upper part. The top of the frame is an arch,
so the corners get cut a little.

Add this STYLE LINE to the end of every prompt, so all images match:
"Photorealistic, premium editorial photography, warm cinematic lighting,
rich deep maroon and antique gold colour palette, soft bokeh background,
shallow depth of field, high detail, natural skin texture, no text, no logos,
no watermark, portrait 4:5."

For people: "South Indian (Tamil) people, natural brown skin tones, black hair,
traditional-modern Tamil Nadu clothing, warm genuine smiles, natural and professional."
